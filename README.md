# AI Native Builder：把 AI 变成组织能力

一本面向企业内部建设者的公开自学书。它从真实业务问题出发，不把大模型等同于完整 AI 系统，而是继续追问：AI 怎样理解组织里的对象、知识、规则和责任，怎样通过 Workflow 与 Agent 产生受控行动，又怎样从 Trace、评估和失败中持续改进。

- [在线阅读](https://kms9.github.io/ai-native-builder-cookbook/zh/)
- [从第 0 章开始](https://kms9.github.io/ai-native-builder-cookbook/zh/chapters/00-getting-started)
- [查看练习册](https://kms9.github.io/ai-native-builder-cookbook/zh/practice/workbook)
- [下载《从 SOP 到智能体应用》](https://kms9.github.io/ai-native-builder-cookbook/downloads/sop-to-agent-application.pdf)

当前工作分支版本：`v0.4.0-dev`；状态：结构升级中，尚未宣布正式发布。

## 内容结构

- 第 0—4 章：角色为什么出现
- 第 4A—4C 章：看见 AI 系统背后的企业——业务架构、知识与 Operational Ontology、Workflow 与 Agent 应用能力
- 第 5—8 章：完成一次端到端建设
- 第 9—10A 章：从试点走向组织能力，并建立运行经验回流闭环
- 第 11 章：用作品说明能力
- 配套练习册、案例、术语表和参考资料

整条课程主线围绕一个问题展开：**AI 怎样进入一个真实组织，理解业务世界，并产生可靠行动？**
