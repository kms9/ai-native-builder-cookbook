## 四部分学习路径

1. **角色为什么出现**：理解企业 AI 建设中的责任断层，以及外部 FDE 与内部 AI Native Builder 的合作边界。
2. **完成一次端到端建设**：从可验证场景走到工作流、智能体约束、运行系统和评估治理。
3. **从试点走向组织能力**：判断真实采用、产品责任、资产复用和退役。
4. **用作品说明能力**：用主张、证据和限制完成毕业项目与同行复核。
