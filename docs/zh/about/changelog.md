# AI Native Builder 版本变更记录

本文件记录读者可感知的内容变化和验证边界。当前版本号、更新时间和状态以 [课程首页](../index.md#当前版本与发布边界) 为唯一事实源；这里不单独宣布正式发布。

## 0.4.0-dev｜2026-08-27

当前状态：结构升级工作分支。

这一轮没有改写原有端到端建设主线，而是在第 4 章与第 5 章之间补上此前缺失的上层坐标，并在第 10 章之后补上运行经验回流。

### 新增

- 第 4A 章《先把 AI 放回真实业务世界》：从业务结果、Business Capability、Decision、流程、角色和系统重新定位 AI 项目；
- 第 4B 章《让 AI 读懂同一个业务世界》：区分知识资产、Taxonomy、领域模型、Operational Ontology 与 Provenance，并继续使用澄川会议、商机、产品资料和 CRM 变更案例；
- 第 4C 章《把业务能力交给 Workflow 与 Agent》：区分 Rule、Function、Action、Tool、Skill、Workflow、Agent 与 Runtime，明确确定性边界和模型判断的分工；
- 第 10A 章《让每次执行反过来改进系统》：把 Trace、Failure Taxonomy、Knowledge / Ontology / Skill / Rule / Workflow / Runtime 改动和 Regression Eval 串成组织学习闭环。

### 主线调整

- 课程总问题收敛为“AI 怎样进入一个真实组织，理解业务世界，并产生可靠行动”；
- 导航从四部分调整为五部分，在角色定位与端到端建设之间增加“看见 AI 系统背后的企业”；
- 首页和 README 增加业务架构、知识与业务语义、Agent 应用能力和组织学习闭环，不再只以“做出一个 AI 应用”描述课程终点；
- 新增内容继续使用“澄川工业客户跟进助手”同一教学世界，没有另起一套企业案例。

### 当前仍待补齐

- 第 0、7、8、10、11 章的少量交叉引用和课程验收项还需要进一步对齐；
- 术语表与参考资料页需要补充 Business Capability、Operational Ontology、Provenance、Action、Runtime、Organizational Learning Loop 等条目；
- 完成全站 Markdown 链接、导航、构建和独立试读检查后，再决定是否进入 `0.4.0-rc`。

## 0.3.0-rc.1｜2026-08-10

当前状态：公开评审稿（发布候选）。

### 工作副本修订｜2026-08-17

尚未改版本号。这一轮只修自学时会迷路的硬冲突：

- 第 4 章补上与第 3 章角色契约的时间线：事故发生在契约已约定、但尚未写成系统约束之后；
- 逐动作五档与术语表、练习册对齐；澄川观察次数、写入工具名和 `CRMChangeSet` 状态与第 5、7 章对齐；
- 第 6A 章不再被写成新的阶段关卡；转化卡只转记第 6 章决定；
- 练习册补上第 0 章承诺的八类能力前测；三处练习册标题加上稳定锚点；
- 补齐澄川业务约束卡填写示例，并在第 7 章回写为系统约束版；资料冲突样本先被跑通，超时未知状态作为新增系统样本。

### 已纳入

- 明确外部 FDE 与内部 AI Native Builder 是合作和对照关系，不存在角色继承关系；
- 完成第 0—11 章、练习册、术语表和参考资料的公开自学主线；
- 增加第 6A 章与 SOP 到智能体约束转化卡，把目标流程转换为可评审的智能体约束；
- 增加内部实践的脱敏教学案例、章节旁注和需求分流练习扩展；
- 串联第 6 章、第 6A 章、第 7 章及配套练习入口；
- 增加来源类型、版本边界、发布条件和公开反馈入口；
- 删除正文中的阶段编号，把章节判断统一改成自然语言；
- 将内部建设说法改成试点范围、可运行方案或具体工作范围；
- 简化 SOP 到智能体约束转化卡的文件名，并更新全书链接。

### 已关闭的最高优先级发布阻断

- 确认 kms9 为作者及全书原创内容权利人；
- 书稿和原创配套 PDF 统一采用 CC BY-SA 4.0，增加 LICENSE 与贡献许可说明；
- 确认《从 SOP 到智能体应用》为作者原创配套资料，并在 PDF 内补充作者、许可和来源页；
- 删除内部实践案例中的实名、交流日期和可识别标识，将量化事实主张改为教学展示与证据边界。

### 已完成的本地检查

- Markdown 前置元数据完整性检查；
- 本地 Markdown 链接、锚点、表格和代码围栏检查；
- 本机路径、常见访问令牌和内部地址模式扫描；
- 外部链接可用性复核；
- 配套 PDF 页数、元数据、授权页和逐页渲染检查。

这些检查只说明当前文件结构和公开内容卫生，不等于完成独立试读、专业审读或正式发布。

### 正式发布前待完成

- 目标读者独立试读、领域审读和文字校对；
- 外部链接、目标导出格式、正式版本号和生效日期复核。
