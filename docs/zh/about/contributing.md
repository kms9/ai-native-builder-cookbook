# AI Native Builder 内容贡献说明

项目通过 [GitHub Issues](https://github.com/kms9/ai-native-builder-cookbook/issues) 接收错别字、失效链接、事实疑点、自学障碍和内容建议。涉及结构、新案例、角色定义或大段改写时，请先提交 Issue 说明问题、证据和建议边界。

## 提交内容前

- 确认内容由你原创，或者你拥有按本项目许可提交和再授权所需的权利；
- 为外部事实提供可核对的一手来源，并说明来源不能证明什么；
- 删除个人信息、客户标识、访问凭证、内部地址、合同内容和未公开系统细节；
- 不要提交无法说明权利来源的长段转载、截图、数据集、图示或 PDF；
- 说明 AI 参与了哪些步骤，以及哪些来源、事实和最终判断经过人工核验。

## 贡献许可

提交 Issue 不会自动转移内容权利。提交 Pull Request 或其他准备合并的内容时，你确认自己有权提交，并同意合并后的贡献按本项目的 [CC BY-SA 4.0 内容许可](https://github.com/kms9/ai-native-builder-cookbook/blob/main/LICENSE)公开。

如果你的材料需要不同许可、保密处理或额外署名，请不要直接提交 Pull Request；应先在不暴露敏感信息的前提下与维护者确认。

## 维护者检查

维护者会检查内容是否符合全书主线，来源是否直接支持主张，案例是否说明脱敏改写或证据等级，练习是否有完成判断，以及修改是否引入新的权利、隐私或跨章一致性问题。
